Oracle 저장 구조·I/O·캐시 요약

객체가 저장 공간을 얻는 방식부터 블록 접근, I/O와 캐시까지 한눈에 정리합니다.

객체와 저장 구조

객체(예: 테이블, 인덱스)는 데이터베이스의 논리적 대상입니다. 실제 공간을 쓰는 저장 구조에는 세그먼트가 사용됩니다. 테이블 데이터와 인덱스는 별도 세그먼트일 수 있고, 뷰처럼 메타데이터만 가지는 객체는 세그먼트가 없을 수 있습니다.

테이블스페이스 → 세그먼트 → 익스텐트 → 데이터 블록은 Oracle의 논리적 저장·할당 계층입니다. 세그먼트는 익스텐트들을 묶어 객체의 저장 공간을 추적하고 필요할 때 확장합니다. 익스텐트는 논리적으로 연속된 여러 Oracle 블록을 한 번에 할당한 단위입니다.

데이터 파일은 블록을 담는 물리 파일입니다. 세그먼트의 익스텐트들은 같은 테이블스페이스 안의 여러 데이터 파일에 놓일 수 있지만, 익스텐트 하나는 한 데이터 파일 안에 있습니다. 로컬 관리 테이블스페이스는 비트맵으로 여유 공간을 추적합니다.

DBA(Data Block Address)는 데이터 파일 번호와 블록 번호로 블록 위치를 식별합니다. 이는 디스크 장치 주소가 아닙니다. ROWID는 파일·블록 정보에 행 위치를 더해 행을 가리킵니다.

논리적 I/O와 물리적 I/O

논리적 I/O(버퍼 I/O)는 서버 프로세스가 DB 버퍼 캐시의 블록을 읽거나 수정하는 작업입니다. 테이블·인덱스 블록 접근이 대표적입니다. 캐시 미스라면 데이터 파일에서 블록을 읽어 캐시에 올린 뒤 논리적으로 접근할 수 있고, 캐시 히트라면 논리적 접근만 합니다.

SQL 파싱은 라이브러리 캐시와 데이터 딕셔너리 캐시에서 SQL 커서, 객체 정의, 권한 등을 확인합니다. 딕셔너리 캐시 조회는 블록 버퍼 겟과 다릅니다. 다만 딕셔너리 테이블 블록을 가져오면 버퍼 캐시 접근과 경우에 따라 물리적 읽기가 생길 수 있습니다.

Single-block I/O는 한 번에 블록 하나를 읽으며 인덱스 기반 접근에서 흔합니다. Multiblock I/O는 여러 인접 블록을 한 번에 읽으며 전체 테이블 스캔과 인덱스 fast full scan에서 흔합니다. 실제 요청 크기는 설정·플랫폼 한도, 캐시된 블록, 연속해서 읽을 수 있는 범위에 따라 달라지고, Oracle 전체 스캔은 익스텐트 경계에서 요청이 줄어들 수 있습니다.

BCHR와 튜닝의 관점

버퍼 캐시 히트율(BCHR)은 관찰 구간의 적중 비율입니다. Oracle의 대표 계산식은 1 - physical reads cache / (consistent gets from cache + db block gets from cache)입니다. 부하 구간의 통계 차이를 비교해야 의미가 있습니다.

히트율과 접근 패턴이 비슷하면 논리적 블록 요청이 감소할수록 물리 읽기 블록도 대체로 줄지만, BCHR은 고정 법칙이 아닙니다. 실행 계획, 캐시 상태, 직접 경로 읽기 등이 관계를 바꿉니다. 물리 읽기 블록 수와 실제 I/O 요청 횟수도 같지 않을 수 있습니다. SQL 튜닝은 BCHR만 올리는 것이 아니라 불필요한 접근을 줄이고 응답 시간과 병목을 개선하는 일입니다.

큰 순차 스캔은 여러 블록을 효율적으로 읽을 수 있습니다. I/O 개수나 크기를 무조건 줄이기보다 실제 작업과 병목을 기준으로 판단합니다.

라이브러리 캐시, 버퍼 캐시, 래치

라이브러리 캐시는 실행 가능한 SQL·PL/SQL과 재사용 가능한 커서를 저장합니다. DB 버퍼 캐시는 데이터 파일에서 읽은 Oracle 데이터 블록의 사본을 저장합니다. 둘 다 SGA의 소프트웨어 관리 메모리 캐시이며 CPU 하드웨어 캐시와는 다릅니다.

버퍼 캐시에서 블록을 찾을 때 해시로 버퍼 체인을 선택하고 체인 안에서 탐색합니다. cache buffers chains 래치는 이 공유 메모리 구조를 검색·수정하는 짧은 구간을 보호합니다. 래치는 행이나 트랜잭션을 보호하는 enqueue 락과 다릅니다.

특정 블록이나 체인에 접근이 몰리면 래치 경합으로 대기와 동시성 저하가 생길 수 있습니다. 불필요한 버퍼 겟을 줄이는 SQL 튜닝이 도움이 되지만, 핫 블록의 원인에 따라 데이터 구조나 애플리케이션 접근 방식도 조정해야 합니다.
